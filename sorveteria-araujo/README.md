# Cardápio digital – Sorveteria Araújo (Parnaíba-PI)

Estilo "cor de sorvete": rosa, menta, cajá e açaí, fonte Lilita One e uma
casquinha ilustrada. Com o scroll, cada bola ganha destaque (Tapioca, Caju,
Abacate), o fundo vira a cor do sabor e cai uma bola bônus (Brownie).
Um único arquivo: `index.html`.

# Site – Pizzaria Rústica (Parnaíba-PI)

Site de demonstração para apresentar à pizzaria. Um único arquivo: `index.html`.

## Antes de entregar ao cliente
Edite o bloco `CONFIG` e `MENU` no fim do `index.html`:
- `whatsapp`: número real (ex.: `5586999999999`)
- `instagram`: confirmar o perfil
- endereços, telefones e horários das unidades
- preços e sabores reais do cardápio
- trocar as fotos de banco de imagens por fotos da pizzaria
- trocar os depoimentos de exemplo por avaliações reais
- remover a faixa "Proposta de site" (`<div class="demo-bar">`)

## Publicar grátis
GitHub Pages, Netlify ou Vercel: basta enviar a pasta.

## Cardápio digital pixel art
`cardapio.html`: cardápio estilo videogame retrô (8-bit), com sons, carrinho
("inventário") e envio do pedido pelo WhatsApp. Edite o `CONFIG` e o `MENU`
no fim do arquivo, do mesmo jeito que no site. Ideal para QR Code na mesa.

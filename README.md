# weather-dashboard

Este repositório contém o **ORION AI**, um assistente pessoal multimodal (conversa com IA, voz, visão computacional, gestos, projetos e memória), na pasta [`orion-ai/`](orion-ai/README.md).

```bash
cd orion-ai && npm install && cp .env.example .env && npm run dev
```

Veja [`orion-ai/README.md`](orion-ai/README.md) para a arquitetura, a segurança, os testes e o status das funcionalidades.
